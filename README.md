# The Honest Million

Artemis 2026 · Problem Statement 1

A calm, one-decision-at-a-time planner for a first-time investor (Aarav, 19).

## Structure

- `app/`: React + Vite + TypeScript build (engine, home, investments)
- `reference/`: complete working prototype with all screens, the AI assistant, and the bear-market simulator
- `docs/`: PRD and build workflow

## Run the prototype

Open `reference/index.html` with the Live Server extension in VS Code, or double-click it.

## Run the React app

    cd app
    npm install
    npm run dev
